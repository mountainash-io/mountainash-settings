# Learning Graph for Mountainash Settings

This section contains the learning graph for the mountainash-settings package -- a typed configuration framework for Python applications built on Pydantic.

The graph maps 110 concepts covering base settings, parameters, field templating, secrets resolution, connection profiles, registry, auth system, caching, and app settings.
