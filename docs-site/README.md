# Documentation sources

The current 0.1.0 API is documented in the [package guide](../README.md),
[profile guide](../docs/profile-spec-pattern.md) and
[migration guide](../docs/migration-0.1.md).

`profile/` retains generated analysis of the 2026-05-13 source revision recorded
in its manifest. `learning-graph/` and its copies in `site/docs/learning-graph/`
are derived educational snapshots, not a current API reference. Their descriptor,
auth and provider examples do not establish support in 0.1.0. Their provenance
has not been regenerated by the API reset.

`site/` holds the published manual. Current profile and registry chapters use
canonical names; consult the migration guide for the complete breaking-change
contract and target-adapter example.
